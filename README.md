# CodeAlpha – Phishing Awareness Training

**Author:** Kalkidan Tewodros

## Project Overview
This project is a Phishing Awareness Training presentation created as part of the CodeAlpha Cyber Security Internship.

The purpose of this project is to educate people about phishing attacks, help them recognize suspicious messages, and understand how to protect themselves from online scams.

## Topics Covered
- Introduction to phishing
- Meaning of phishing
- Different types of phishing attacks
- Warning signs in phishing emails
- Recognizing suspicious messages
- Phishing prevention and safety awareness

## Tools Used
- Microsoft PowerPoint

## Project Objectives
- Understand what phishing is.
- Learn how phishing attacks work.
- Recognize common warning signs.
- Develop awareness of online security.
- Encourage safe internet practices.

## Learning Outcomes
Through this project, I improved my understanding of phishing attacks, cybersecurity awareness, and online safety practices.
